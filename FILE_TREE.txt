KEY FILES & DIRECTORIES

📁 backend/src/db/schema.sql
   PostgreSQL database schema with all tables, indexes, and constraints
   Auto-loaded on backend startup

📁 frontend/src/context/AuthContext.tsx
   Global authentication state management using React Context
   Provides user data and auth functions to entire app

📁 backend/src/services/
   Core business logic separated by domain
   Handles all database operations and business rules

📁 frontend/src/pages/
   Route-based page components
   Each file = one major page/view in the application

📁 docs/
   Comprehensive documentation
   Start with docs/README.md for navigation

ARCHITECTURE SUMMARY

Monorepo Structure:
├── Backend (Express.js + PostgreSQL)
├── Frontend (React + React Router)
└── Documentation (Comprehensive guides)

Technology Stack:
- Backend: Express.js, TypeScript, PostgreSQL, JWT
- Frontend: React 19, React Router, Axios, CSS
- DevOps: Docker, Docker Compose, pnpm workspaces

QUICK COMMANDS

pnpm install --recursive      # Install all dependencies
pnpm backend:dev              # Start backend in dev mode
pnpm frontend:dev             # Start frontend in dev mode
pnpm dev                       # Start all services in dev mode
docker-compose up -d          # Start with Docker
docker-compose down           # Stop Docker services
